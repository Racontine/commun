Voici les commandes exactes à taper sur le Raspberry Pi pour tout mettre à jour depuis Git (récupérer le nouveau design, le nom Racontine et les correctifs) et réinstaller proprement.

Connectez-vous d'abord : ssh alice@racontine.local
mdp = liseo

Ensuite, copiez-collez ces commandes (bloc par bloc) :

1. Mise à jour propre (méthode recommandée)
Comme vous n'aviez peut-être pas initialisé Git sur le Pi, on va supprimer l'ancien dossier d'installation et retélécharger la version complète propre depuis GitHub. C'est le plus sûr.

bash
# 1. Aller dans le dossier utilisateur
cd /home/alice
# 2. Supprimer l'ancien dossier d'installation (pour éviter les conflits)
sudo rm -rf ALICE_PI_INSTALL
# 3. Télécharger la toute dernière version depuis GitHub
git clone https://github.com/lumios-le-jeu/alice-media.git ALICE_PI_INSTALL
# 4. Entrer dans le dossier
cd ALICE_PI_INSTALL
# 5. Lancer l'installation (va copier les fichiers et redémarrer le service)
sudo chmod +x install_alice_son.sh
sudo ./install_alice_son.sh

🛠️5. Correction si dossier erreur
Essayez ceci sur le Pi :

bash
# Entrer dans le sous-dossier (si structure imbriquée)
cd /home/alice/ALICE_PI_INSTALL/ALICE_PI_INSTALL
# Vérifier si le fichier est là
ls
# Si oui, lancer :
sudo chmod +x install_alice_son.sh
sudo ./install_alice_son.sh
