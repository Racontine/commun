🔄 Le Scénario Idéal pour l'utilisateur
Voici comment cela devrait se passer pour un nouvel utilisateur :

Maison A (Chez vous) :
Tout marche, vous accédez à http://alicepi.local:8080.
Déménagement vers Maison B (Pas encore configuré) :
L'utilisateur branche le Pi.
Le Pi ne trouve pas votre WiFi "Maison A".
🤖 Automatique : Grâce au script autohotspot (déjà installé), après quelques minutes sans connexion, le Pi va tout seul créer le WiFi ALICE_SETUP (ou RACONTINE_SETUP).
L'utilisateur voit le réseau WiFi apparaître sur son téléphone.
Configuration :
L'utilisateur se connecte au WiFi ALICE_SETUP.
Il va sur http://192.168.50.1 (adresse fixe du hotspot).
Il choisit son nouveau WiFi "Maison B" et met le mot de passe.
Le Pi redémarre.
Utilisation Maison B :
Le Pi est maintenant connecté à la box "Maison B".
L'utilisateur scanne votre QR Code http://alicepi.local:8080.
Ça marche ! (Même si l'IP a changé).
💡 En résumé
Le bouton "Configurer WiFi" que nous avons ajouté dans l'interface sert surtout :

Si vous voulez changer de WiFi avant de partir.
Si le mode automatique met trop de temps à se déclencher.
Pour le QR Code définitif, utilisez : http://alicepi.local:8080
