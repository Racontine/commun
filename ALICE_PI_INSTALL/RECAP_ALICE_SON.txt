================================================================
                    INSTALLATION RAPIDE
================================================================

1️⃣  Transférer les fichiers sur le Pi :
    
    scp -r ALICE_PI_INSTALL alice@<IP_PI>:/home/alice/

2️⃣  Se connecter et installer :
    
    ssh alice@<IP_PI>
    cd /home/alice/ALICE_PI_INSTALL
    chmod +x install_alice_son.sh
    sudo ./install_alice_son.sh

3️⃣  Accéder à l'interface :
    
    Ouvrir dans un navigateur :
    http://<IP_DU_PI>:8080

================================================================
                    SERVICES SYSTEMD
================================================================

📊 alice.service
   └─ Application principale (scan QR + lecture audio)
   └─ Commandes :
      • sudo systemctl status alice.service
      • sudo systemctl restart alice.service

🔊 alice_son.service  🆕
   └─ Serveur web de contrôle du volume
   └─ Commandes :
      • sudo systemctl status alice_son.service
      • sudo systemctl restart alice_son.service

🌐 autohotspot.service
   └─ Bascule auto/hotspot (configuration initiale)
   └─ Commandes :
      • sudo bash /home/alice/autohotspot.sh force

================================================================
                    FICHIER CONFIG.JSON
================================================================

Emplacement : /home/alice/media/config.json

Structure :
{
  "volume": 90,          ← Volume (0-100%)
  "wifi_priority": [     ← Priorités WiFi
    "MonWiFi_Maison",
    "MonWiFi_Bureau"
  ]
}

IMPORTANT : Ce fichier DOIT être dans /home/alice/media/ !

================================================================
                    COMMANDES UTILES
================================================================

🔍 Trouver l'IP du Pi :
   hostname -I

🌐 URL d'accès :
   http://<IP_DU_PI>:8080

📊 Voir le statut :
   sudo systemctl status alice_son.service

📜 Voir les logs :
   sudo journalctl -u alice_son.service -f

🔄 Redémarrer :
   sudo systemctl restart alice_son.service

⏹️  Arrêter :
   sudo systemctl stop alice_son.service

🗑️  Désinstaller :
   cd /home/alice/ALICE_PI_INSTALL
   chmod +x uninstall_alice_son.sh
   sudo ./uninstall_alice_son.sh

================================================================
                    DÉPANNAGE RAPIDE
================================================================

❌ La page ne charge pas ?
   → Vérifier : sudo systemctl status alice_son.service
   → Redémarrer : sudo systemctl restart alice_son.service

❌ Le volume ne change pas ?
   → Vérifier que vous avez cliqué sur "Sauvegarder"
   → Attendre 10 secondes (Alice redémarre)
   → Vérifier : cat /home/alice/media/config.json

❌ Service ne démarre pas ?
   → Installer Flask : sudo pip3 install Flask==3.0.0
   → Logs : sudo journalctl -u alice_son.service -n 50
