🐰 Alice Box – Installation WiFi Hotspot (Validé)
Ce guide détaille l'installation finale et fonctionnelle du mode Hotspot.

1. Structure des fichiers (CRITIQUE)
Il est impératif de respecter cette structure sur le Raspberry Pi (/home/alice/) :

/home/alice/
├── alice.py             # Script principal (Mise à jour requise)
├── alice_setup.py       # Serveur Web de config (Mise à jour requise)
├── autohotspot.sh       # Script de bascule Auto/Hotspot
├── autohotspot.service  # Service systemd
├── setup_hostapd.conf   # Config du point d'accès
├── setup_dnsmasq.conf   # Config DHCP
├── templates/
│   └── setup.html       # Page Web (Mise à jour requise)
└── media/
    └── config.json      # settings (Volume) - DOIT ÊTRE DANS MEDIA !
WARNING

Si 
config.json
 n'est pas dans /home/alice/media/, le système passera en mode TEST (Mock) et n'enregistrera pas le WiFi !

2. Installer les dépendances
sudo apt update
sudo apt install hostapd dnsmasq python3-flask

3. Installation & Permissions
# 1. Copier tous les fichiers depuis votre PC vers /home/alice/
# 2. Rendre executable
chmod +x /home/alice/autohotspot.sh
# 3. Installer le service
sudo cp /home/alice/autohotspot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable autohotspot.service
4. Configuration WiFi (Détails Techniques)
Ces réglages ont été validés pour fonctionner sur Raspberry Pi Zero 2W :

SSID : ALICE_SETUP
Mot de passe : alicebox
IP : 192.168.50.1 (Evite les conflits avec 192.168.1.x ou 10.0.0.x)
Canal : 6
Sécurité : WPA2 (Les iPhones rejettent les réseaux ouverts)

5. Comment tester ? (Mode Force)
Pour vérifier le Hotspot sans couper votre box internet :

Connectez-vous en SSH.
Lancez le mode force :
sudo bash /home/alice/autohotspot.sh force
(Votre SSH va couper, c'est normal)
Connectez votre téléphone au WiFi ALICE_SETUP.
Allez sur http://192.168.50.1
Configurez (Volume, WiFi + Priorité).
Validez -> Le Pi redémarre et se reconnecte à votre maison.

6. Dépannage
Je ne vois pas le WiFi : Vérifiez que 
setup_hostapd.conf
 a bien country_code=FR.
Je suis connecté mais pas de page web : Vérifiez que 
alice.service
 est bien arrêté par le script 
autohotspot.sh
 (conflit de ressources).
Le WiFi n'est pas sauvegardé : Vérifiez que 
config.json
 est bien dans le dossier media !
