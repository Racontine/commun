================================================================
                    🔊 ALICE_SON - RÉSUMÉ
================================================================

✅ PROBLÈME RÉSOLU :

   AVANT : Pour changer le son, il fallait utiliser SSH et 
           basculer en mode hotspot (WiFi coupé, ~5 minutes)
   
   MAINTENANT : Interface web accessible directement sans
                couper le WiFi (~30 secondes) !

================================================================

🚀 INSTALLATION (1 FOIS SEULEMENT) :

   1. Transférer les fichiers sur le Pi :
      scp -r ALICE_PI_INSTALL alice@<IP_PI>:/home/alice/

   2. Se connecter et installer :
      ssh alice@<IP_PI>
      cd /home/alice/ALICE_PI_INSTALL
      chmod +x install_alice_son.sh
      sudo ./install_alice_son.sh

   3. Attendre 1 minute → Installation terminée !

================================================================

🎯 UTILISATION (QUOTIDIENNE) :

   1. Ouvrir votre navigateur (PC/Téléphone/Tablette)
   
   2. Aller sur : http://<IP_DU_PI>:8080
   
   3. Ajuster le volume avec le slider (0-100%)
   
   4. Cliquer sur "Sauvegarder"
   
   5. Attendre 5 secondes → Terminé !

================================================================

🔍 TROUVER L'IP DU PI :

   ssh alice@<IP_PI>
   hostname -I

   Exemple : 192.168.1.42
   URL : http://192.168.1.42:8080
