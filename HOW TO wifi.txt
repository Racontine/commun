Sur **Raspberry Pi OS (sans NetworkManager)**, la priorité Wi-Fi se règle **dans `wpa_supplicant.conf`**.
C’est exactement ce que tu avais déjà commencé 👍
Je te redonne la **procédure propre, simple et sûre**.

---

## 1️⃣ Ouvrir le fichier Wi-Fi

```bash
sudo nano /etc/wpa_supplicant/wpa_supplicant.conf
```

---

## 2️⃣ Exemple avec plusieurs réseaux + priorité

👉 **Plus le nombre est grand, plus la priorité est haute**

```conf
ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1
country=FR

network={
    ssid="LeborgneFamily"
    psk="TON_MOT_DE_PASSE"
    priority=80
}

network={
    ssid="Geotrouvetout"
    psk="fiebooth2023"
    priority=50
}

network={
    ssid="Livebox-7118"
    psk="xxxxx"
    priority=10
}
```

✅ Ici :

* **LeborgneFamily** → prioritaire
* Si indisponible → Geotrouvetout
* En dernier → Livebox

---

## 3️⃣ Sauvegarder

Dans nano :

```
CTRL + O → ENTER
CTRL + X
```

---

## 4️⃣ Redémarrer le Wi-Fi (ou le Pi)

Méthode rapide :

```bash
sudo wpa_cli -i wlan0 reconfigure
```

Ou sûr à 100 % :

```bash
sudo reboot
```

---

## 5️⃣ Vérifier le réseau actif

```bash
iw dev wlan0 link
```

Tu dois voir :

```
SSID: LeborgneFamily
```

---

## ℹ️ Notes importantes

* `priority` fonctionne **sans NetworkManager**
* Tu peux monter jusqu’à **priority=100**
* Le Pi se connectera **automatiquement au meilleur réseau dispo**
* Aucun impact sur les QR, audio ou caméra

---

## 🧠 Astuce Alice (recommandé)

Pour un produit final :

* Wi-Fi principal → `priority=80–100`
* Wi-Fi de secours → `priority=20–50`
* Hotspot / setup → `priority=1`
